# Roots & Results

Live repository: https://lesleylearnification.github.io/Roots-and-Results/

**A five-minute serious game about balancing trade-offs and strengthening resilience in agrifood systems.**

Roots & Results is a responsive portfolio repository containing the public overview, an approved Behind the Design case study, and a playable prototype.

## Repository structure

- `index.html` — portfolio overview / landing page
- `design.html` — Behind the Design case study
- `prototype/index.html` — playable browser prototype
- `styles.css` — shared responsive styles
- `script.js` — responsive navigation behavior
- `assets/roots-results-concept.png` — concept art used on the portfolio pages
- `.nojekyll` — GitHub Pages helper

## Case Study

The case study follows the approved eight-part structure:

1. The Challenge
2. Game Fantasy
3. Learning Objective
4. Game Goal
5. Gameplay
6. Motivation
7. Game Inspiration
8. Reflection

The copy is based on the creator-approved Case Study artifact. Only obvious mechanical typos were corrected during repository production.

## Responsive behavior

Designed for desktop, tablet, and mobile with a two-column hero on large screens, stacked layouts at smaller breakpoints, responsive case-study navigation, large touch targets, and horizontally scrollable data tables where needed.

## Publishing on GitHub Pages

Upload the repository contents to the root of the GitHub repository and enable GitHub Pages from the repository's default branch/root directory.
